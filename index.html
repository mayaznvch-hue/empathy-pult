      Введи фамилию. Пульт найдёт все адреса врача в карте сайта и соберёт строки для .htaccess (блок «####уволенные»).

      Найденные адреса

        Строки для .htaccess

        1. Сначала скачай копию .htaccess (на всякий случай для отката).
        2. Вставь строки под строкой ####уволенные. Формат только простой: Redirect 301 путь адрес. На этом сервере nginx, RedirectMatch не работает.
        3. В админке выключи активность у карточки врача и его услуг, иначе он вернётся в карту сайта.
        4. Проверить: вкладка «Здоровье сайтов» после следующей проверки или curl -I адрес.
        Данные о сайтах — публичные, обновляются GitHub Actions. Пароли пульт не хранит и не спрашивает.
